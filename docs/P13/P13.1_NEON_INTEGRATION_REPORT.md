## 7. Hướng dẫn thao tác thủ công (chủ dự án)

> ⚠️ **Không** dán connection string/secret vào hội thoại, commit, hoặc báo cáo.
> Đặt qua Environment Variables của môi trường deploy hoặc `.env.local` trên máy cá nhân.

```bash
# 0) Cấu hình (pooled cho runtime, direct cho migration)
export DATABASE_URL="postgresql://…-pooler….neon.tech/DB?pgbouncer=true&sslmode=require"
export DIRECT_URL="postgresql://…direct….neon.tech/DB?sslmode=require"

# 1) Sinh Prisma Client
pnpm db:generate

# 2) Kiểm tra lịch sử migration (KHÔNG đổi dữ liệu)
pnpm prisma migrate status

# 3) Chỉ khi xác nhận ĐÚNG database đích Neon + đã review migration:
pnpm prisma migrate deploy        # KHÔNG dùng db push / migrate reset

# 4) Seed hệ thống (idempotent, an toàn chạy lại)
pnpm db:seed

# 5) Kiểm chứng kết nối (script chỉ đọc, không in secret)
pnpm tsx scripts/verify-db.ts
```

**Trên Vercel (Production & Preview):** đặt `DATABASE_URL` (pooled) và `DIRECT_URL` (direct) trong
Environment Variables; chọn Node 22.x; redeploy và xác nhận build log **không** còn
"Failed to collect configuration for /api/v1/admin/recipes".

**Lưu ý Neon:**
- `DATABASE_URL` = endpoint **pooled** + `?pgbouncer=true` (tắt prepared statement cho PgBouncer).
- `DIRECT_URL` = endpoint **direct** (không pooler) — **bắt buộc** cho `prisma migrate`.
- Không xóa migration cũ để xử lý lỗi; nếu migration thất bại → **dừng**, ghi nhận, đề xuất khắc phục an toàn.
