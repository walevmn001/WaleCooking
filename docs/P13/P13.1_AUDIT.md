## 5. Kiểm tra biến môi trường (`lib/config/env.ts`)

| Biến | Bắt buộc | Ghi chú |
|---|---|---|
| `NODE_ENV` | default `development` | enum |
| `DATABASE_URL` | **Bắt buộc** (runtime có truy vấn) | phải khớp `^postgres(ql)?://` |
| `DIRECT_URL` | Optional trong schema env | **Bắt buộc** khi chạy `prisma migrate` (đọc trực tiếp bởi Prisma CLI) |
| `TEST_DATABASE_URL` | Optional | CSDL cho integration test |
| `AUTH_*`, `R2_*`, `MEDIA_LOCAL_DIR` | Optional | ngoài phạm vi P13.1 |

- `serverEnv()` **lazy + memoized**; lỗi chỉ **nêu TÊN biến**, **không** in giá trị.
- `hasR2Config()` dùng cho media adapter (ngoài phạm vi).

**Nhận định:** cơ chế đọc env đã an toàn. Với Neon: `DATABASE_URL` = **pooled** (`?pgbouncer=true`),
`DIRECT_URL` = **direct** (không pooler) cho migration.

## 6. Connection pooling & tương thích Neon

| Hạng mục | Hiện trạng | Khuyến nghị P13.1 |
|---|---|---|
| Pooled runtime | Chưa có ràng buộc đặc thù Neon trong code | `DATABASE_URL` thêm `?pgbouncer=true&sslmode=require` |
| Direct migration | `directUrl = env("DIRECT_URL")` | `DIRECT_URL` = endpoint **direct** Neon |
| Vercel serverless | Mỗi function 1 process | Cân nhắc `connection_limit=1` (không bắt buộc) |
| Prepared statements | Prisma 6 tương thích PgBouncer khi có `?pgbouncer=true` | Bắt buộc cờ khi dùng pooler Neon |

**Nhận định:** **không có** tham số pooling hardcode trong mã nguồn (kiểm bằng grep). Nếu cần điều
chỉnh, chỉ điều chỉnh qua chuỗi kết nối trong biến môi trường — **không** hardcode.

## 7. Thành phần truy cập database

**Repository (`lib/db/repositories/`):** `prisma.ts` (client), `repositories/index.ts` (cổng
`unit`/`taxonomy`/`ingredient`/`recipe`/`media`), adapter Prisma tương ứng.

**Service (`lib/services/`):** `catalog.service.ts`, `recipe.service.ts`, `taxonomy.service.ts`,
`media.service.ts` — dùng qua cổng `repositories` (UI **không** gọi Prisma trực tiếp).

| `recipes/[id]/route.ts` | get/patch/delete |
| `recipes/[id]/{publish,archive,submit-review,versions}/route.ts` | workflow |
| `admin/recipes/route.ts` | danh sách quản trị (route từng lỗi "Failed to collect configuration") |
| `admin/taxonomy/{route,[id]/route}.ts` | CRUD taxonomy |
| `media/{route,[id]/route}.ts` | media |
| `kitchen/ingredient-match/route.ts` | khớp nguyên liệu |

**UI đọc DB (Server Components):** `app/(public)/cong-thuc/*`, `app/(public)/danh-muc/*`,
`app/sitemap.ts` (try/catch quanh DB).
