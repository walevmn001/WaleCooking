## 4. TẦNG ỨNG DỤNG — ĐÃ KIỂM CHỨNG BẰNG CODE

### 4.1 Recipe (Application/Domain)

- `lib/services/recipe.service.ts` — `RecipeService`: `listPublic`, `listPublicForCategory`, `getPublicBySlug`, `getPublicSummariesBySlugs`, `matchByIngredients`, `listAdmin`, `create`, `update`, `submitForReview`, `publish`, `archive`, `remove`, `listVersions`.
  - **Ghi công thức** = `create()` → `recipeRepository.create(...)` nhận `CreateRecipeInput` (slug, authorId, translations fields, ingredients[], steps[], sourceIds[], allergenSlugs[], taxonomyTerms[], images[]). **Đây là điểm đến của dữ liệu importer sau khi admin duyệt.**
  - **Publish** = `assertPublishable()` bắt buộc: title, summary, foodTypeSlug, cuisineSlug, `baseServings > 0`, thời gian, ≥1 nguyên liệu, ≥1 bước, **ảnh đại diện**, **≥1 nguồn** (BR-01/BR-03).
- `lib/db/repositories/recipe.repository.ts` — interface `RecipeRepository` + DTO (`RecipeSummaryDto`, `RecipeDetailDto`, `CreateRecipeInput`, `UpdateRecipeInput`…). Tìm kiếm hiện dùng `contains` + `mode: "insensitive"` (xác nhận ở `prisma-recipe.repository.ts` — **chưa** FTS).
- `lib/services/homepage.service.ts` — mẫu **tách lỗi độc lập từng khối** + `Promise.all` (không N+1) — **tái sử dụng pattern này cho batch có failure isolation.**

### 4.2 Media / Storage

- `lib/storage/storage.port.ts` — `StoragePort` (`put/delete/publicUrl/getSignedUrl?`) + `provider: "r2" | "local"`.
- `lib/storage/index.ts` — `getStorage()` lazy + **guard production** (thiếu `R2_*` → ném lỗi, không ghi FS tạm) — sửa ở P12 (FIND-07).
- `lib/storage/image-validation.ts` — magic bytes: **chỉ JPEG/PNG/WebP/AVIF**, ≤ **8 MB/ảnh**, cạnh ≤ 8192 px. **Tái dùng cho ảnh importer.**
- `lib/services/media.service.ts` — upload qua adapter, khóa do server sinh `recipes/YYYY/MM/<uuid>-<slug>.<ext>`; `archive()` chặn khi còn tham chiếu.

### 4.3 Authorization (RBAC tập trung)

- `lib/auth/authorization.ts` — `Actor {id, role}`, roles `user|editor|admin`, `Permission` union (`recipe:create/update/publish/archive/read:draft/delete`, `media:upload`, `taxonomy:manage`, `user:manage`, `favorite:manage`), `requirePermission/can/hasRole`.
- `lib/auth/session.ts` — `getCurrentActor()` → **hiện trả `null`** (Auth.js **chưa nối**). Mọi thao tác ghi trả **401** qua `requirePermission`.
- **Chưa có permission dành cho importer** (vd `import:manage`) → đề xuất bổ sung ở P16.7 (không sửa code trong P16).

### 4.4 API & lỗi

- Route Handler pattern: `app/api/v1/**/route.ts` dùng `handle()` + `jsonOk()` (`lib/api/http.ts`) và `getCurrentActor()`.
- Lỗi: `lib/errors/app-error.ts` — `AppError` + `toErrorResponse()` (400/401/403/404/409/**422**/500; message an toàn, không lộ stack).
- Contract API: `docs/P02/API_CONTRACT.md` (base `/api/v1`, phân trang, validation 422, idempotency header).

### 4.5 Validation

- `lib/validation/*` (Zod): `recipe.ts` (`createRecipeSchema`, `updateRecipeSchema`, `listRecipesQuerySchema`, `matchByIngredientsQuerySchema`), `common.ts`, `taxonomy.ts`, `catalog.ts`. Định lượng là **chuỗi thập phân**, có `quantityType` (`decimal/fraction/range/text`).

### 4.6 Config / môi trường

- `lib/config/env.ts` — `DATABASE_URL` (bắt buộc runtime), `DIRECT_URL`, `TEST_DATABASE_URL`, `AUTH_SECRET/AUTH_URL`, `R2_ACCOUNT_ID/ACCESS_KEY_ID/SECRET_ACCESS_KEY/BUCKET/PUBLIC_BASE_URL`, `MEDIA_LOCAL_DIR`. **Không in giá trị secret khi lỗi.** → Import cần thêm biến cho AI/HTTP client (đề xuất ở P16.8), **chưa** khai báo trong P16.

## 7. NHỮNG GÌ **CHƯA THỂ KIỂM CHỨNG** (giới hạn của audit)

1. **Neon/R2/Vercel thật** — không credentials trong sandbox → các đặc tính production (latency, hạn mức thực tế, egress) **chỉ là số liệu tài liệu**, không đo được.

3. **Robots.txt / ToS / cấu trúc HTML của website nguồn** — P16 **không** truy cập Internet để crawl thử (đúng nguyên tắc "không truy cập/ghi dữ liệu production", và tránh hành vi thu thập ngoài phạm vi). → Chiến lược nguồn dựa trên **thiết kế + nguyên tắc pháp lý**, có danh sách nguồn **minh hoạ**, không cam kết "đã kiểm từng site".
4. **Chất lượng mô hình AI dịch/trích xuất** — chưa có credentials AI → thiết kế ở mức **interface + guardrail**, không benchmark.
5. **Lịch sử Git đầy đủ** — shallow clone.
