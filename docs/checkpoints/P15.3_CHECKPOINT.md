## 1. Bối cảnh

`app/(public)/tim-kiem/page.tsx` trước đây chỉ là `PlaceholderPage` (phase P06). P15.3 thay bằng trang
tìm kiếm thật, tái sử dụng hạ tầng đã có từ P07/P08 (`recipeService.listPublic`, `RecipeFilters`,
`RecipeCard`, `Pagination`, `EmptyState`, `ErrorState`) — KHÔNG đổi semantics tìm kiếm.

## 2. Chức năng đã triển khai

| Yêu cầu | Cách thực hiện |
|---|---|
| Nhận `q` | `parseRecipeListParams` + truyền `safeQuery` vào `recipeService.listPublic` |
| Bộ lọc hiện có | `foodType`, `cuisine`, `difficulty`, `mealType`, `cookingMethod`, `dietary`, `maxMinutes`, `sort` (qua `RecipeFilters` + `listRecipesQuerySchema`) |
| Phân trang | `Pagination` với `hrefFor(page) = buildRecipeListHref(params, { page }, "/tim-kiem")` |
| Đồng bộ URL / chia sẻ | Toàn bộ trạng thái nằm trên query string; mọi thao tác lọc điều hướng client lên URL |
| Giữ validation | Dùng nguyên `listRecipesQuerySchema` (không nới lỏng, không thay semantics) |
| Param không hợp lệ | `sanitizeRecipeListQuery()` loại bỏ trường sai thay vì ném lỗi (không lỗi server) |
| Xoá từ khoá | `RecipeFilters` submit rỗng → URL không còn `q` (giữ bộ lọc khác); “Xoá bộ lọc” → `/tim-kiem` |

## 3. Trạng thái giao diện

- **Chưa nhập từ khoá** (không `q` và không bộ lọc): khối “Bắt đầu tìm kiếm” — hướng dẫn + gợi ý nhanh
  theo loại món (taxonomy thật, link `/tim-kiem?foodType=...`) + 4 lối vào khám phá thật
  (`/cong-thuc`, `/danh-muc`, `/cong-cu/tim-theo-nguyen-lieu`, `/cong-cu`).
- **Có kết quả**: hiển thị `{data.total} kết quả` (đếm THẬT từ DB) + lưới `RecipeCard` (kèm `FavoriteButton`).
- **Không kết quả**: `EmptyState` rõ ràng + gợi ý bỏ bớt bộ lọc + hành động “Xoá bộ lọc”.
- **Lỗi**: `ErrorState` (`role="alert"`) + nút “Thử lại” (link về URL hiện tại); ghi log `console.error`.
