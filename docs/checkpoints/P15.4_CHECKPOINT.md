## 1. Bối cảnh

P15.1–P15.3 đã dựng trang chủ dữ liệu thật và trang tìm kiếm công khai. P15.4 kiểm chứng các khía cạnh
UX/trợ năng bắt buộc (loading/soft-404, empty/error state, bảo toàn query/filter, back/forward, heading
ngữ nghĩa, điều hướng bàn phím, focus visible, nhãn trợ năng, không tràn ngang ở 375/390/768/1440px) và
mở rộng bộ kiểm thử trình duyệt (Playwright/CDP) để các tiêu chí này được kiểm chứng **thực tế**, không
chỉ bằng suy luận.

Lần đầu trong phase P15, E2E chạy được trong sandbox: PostgreSQL cục bộ có sẵn DB riêng `wale_e2e`
(migration + fixture `e2e-`), Chrome chạy sẵn với `--remote-debugging-port=9222`, server production build
trên `http://127.0.0.1:3000`.

## 2. Kết quả rà soát UX / trợ năng

| Hạng mục | Phát hiện | Hành động |
|---|---|---|
| Loading không tạo soft-404 | **Không** có `loading.tsx` nào dưới `app/` (đã bỏ ở P11) → Suspense boundary không làm route con trả HTTP 200. | Giữ nguyên, KHÔNG khôi phục |
| Empty state | Trang chủ: `EmptyState` "Thư viện đang được xây dựng" khi cả món mới & danh mục rỗng. Tìm kiếm: `EmptyState` + nút "Xoá bộ lọc". | Đã kiểm chứng bằng E2E |
| Error state | Trang chủ: khối lỗi → `null` → ẩn (không hỏng trang). Tìm kiếm: `ErrorState` (`role="alert"`) + "Thử lại". | Đã kiểm chứng bằng unit + E2E (E2E xác nhận không lỗi server) |
| Bảo toàn từ khoá | Nhập `q` khiến URL `/tim-kiem?q=...`; nút "Xoá bộ lọc" → `/tim-kiem`. | E2E: `back/forward` giữ `?q=Canh` |
| Bảo toàn bộ lọc khi phân trang | `Pagination.hrefFor = buildRecipeListHref(params, { page }, "/tim-kiem")` giữ mọi tham số. | Đã có unit test `buildRecipeListHref`; E2E bộ lọc cập nhật URL |
| Back/forward | Điều hướng tới chi tiết rồi `goBack()` trở lại đúng `/tim-kiem?q=Canh` kèm kết quả. | E2E (P15.4) |
| Heading ngữ nghĩa | **Phát hiện lỗi**: khối kết quả tìm kiếm chỉ có `<p>` đếm, không có `h2` → nhảy bậc `h1 → h3`. | **Đã sửa**: bọc `<section aria-labelledby>` + `h2` "Kết quả tìm kiếm" |
| Điều hướng bàn phím | Tab tới được ô tìm kiếm ở cả header (chỉ desktop) và hero/khối lọc. | E2E (P15.4) |
| Focus visible | Mọi control dùng `focus-visible:focus-ring` (outline/box-shadow). | E2E: ô tìm kiếm trên `/tim-kiem` có dấu hiệu focus |
| Nhãn trợ năng | Ô tìm kiếm có `aria-label`; nút lọc gắn với `<label>` (implicit). | E2E `getByLabel("Loại món"/"Sắp xếp")` |
| Screen reader semantics | Số kết quả công bố qua `aria-live="polite"` (đếm THẬT); toast cũng dùng `aria-live` (đã scope selector). | E2E |
| Không tràn ngang | 0 tràn ngang ở cả 4 viewport trên 9 trang chính (đã thêm `/tim-kiem`, `/tim-kiem?q=Canh`). | E2E responsive |

## 4. Thay đổi mã nguồn

**Thêm mới:** không có file mới trong mã sản phẩm.

**Sửa đổi:**
- `app/(public)/tim-kiem/page.tsx` — bọc khối kết quả trong `<section aria-labelledby="search-results-heading">`
  + `h2` "Kết quả tìm kiếm"; giữ `aria-live="polite"` cho số kết quả (đếm THẬT). Chỉ đổi cấu trúc ngữ nghĩa,
  KHÔNG đổi cách truy vấn/kết quả.
- `tests/e2e/public.e2e.ts`:
  - Sửa test trang chủ stale → CTA "Khám phá thư viện"; thêm kiểm tra ô tìm kiếm hero.
  - Thêm test khối "Món mới" hiển thị công thức `published` thật, KHÔNG lộ bản nháp.
  - Thêm `describe` "Public — tìm kiếm công khai (FR-05)": thay PlaceholderPage, tìm từ trang chủ → `/tim-kiem?q=`,
    lọc cập nhật URL, trạng thái rỗng + "Xoá bộ lọc", tham số URL không hợp lệ không lỗi server, back/forward.
- `tests/e2e/responsive.e2e.ts`:
  - Thêm `/tim-kiem` và `/tim-kiem?q=Canh` vào `PAGES` (kiểm tra tràn ngang + console/lỗi request ở 4 viewport).
  - Thêm `describe` "Trợ năng — trang chủ & tìm kiếm (P15.4)": đúng một `h1` mỗi trang, region + heading ngữ nghĩa,
    nhãn bộ lọc, `aria-live` số kết quả, và Tab tới ô tìm kiếm với focus hiển thị.
