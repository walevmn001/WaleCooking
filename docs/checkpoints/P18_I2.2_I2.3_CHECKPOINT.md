## 4. Tiền đề I2.3 — spike cơ chế IP pinning (chưa vào code sản phẩm)

Spike cục bộ (`spike-pin.mjs`, `spike-pin2.mjs`, tạm) đã chứng minh trên Node `v24.1.0`:
- `node:http`/`node:https` với option `lookup` (custom resolver) **pin IP** đã kiểm (hostname không có DNS vẫn kết nối tới IP chỉ định; `lookupCalls=1`).
- Phân biệt IP đích (`127.0.0.1` vs `127.0.0.2` → hai server khác nhau) ⇒ kết nối đi **đúng** IP đã chọn.
- **TLS/SNI** giữ hostname gốc (server thấy `servername=recipe.test`); cert sai hostname bị từ chối (`ERR_TLS_CERT_ALTNAME_INVALID`).
- `undici` **không** là dependency dự án ⇒ dùng `node:http`/`node:https` built-in.

> Đây là tiền đề cho M4; phần **chứng minh chính thức bằng integration test** (đo địa chỉ kết nối thực tế) sẽ hoàn tất ở M4/M6.
