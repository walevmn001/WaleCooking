## 2. Nội dung đã hoàn thành
- Mô hình mối đe dọa + phân tích **13 nhóm rủi ro**: SSRF, localhost/private IP, DNS rebinding, redirect nội bộ, ảnh độc hại, file quá lớn, HTML độc hại, prompt injection, AI xử lý nội dung không tin, lạm dụng API, chi phí AI, quá tải DB, rate limit/blocking.
- Biện pháp bảo vệ: URL allow/deny, chặn private/reserved/metadata IP, **resolve-once + pin IP** chống DNS rebinding, kiểm lại mỗi redirect (≤5), chỉ http/https, giới hạn response size/timeout/MIME, **không thực thi JS**, sanitize HTML, **không coi nội dung web là instruction**, RBAC + AuditLog, giới hạn concurrency & chi phí.
- **Thứ tự 8 bước kiểm tra URL** (gồm pin IP + kiểm mỗi hop) + **checklist bảo mật 10 mục**.
- **Đánh giá bản quyền**: không mặc định được phép sao chép công thức/ảnh; phân biệt **facts / cách diễn đạt / ảnh / nội dung sáng tạo**; attribution bắt buộc (BR-03); xác định chính sách tái sử dụng **trước khi publish**; **không** vượt paywall/CAPTCHA/anti-bot.
- **Giới hạn tài nguyên/chi phí** bám nền tảng free (Vercel/Neon/R2) + ngân sách AI + cache.
- Rủi ro còn lại (chưa giải quyết ở P16): chưa có test SSRF guard, chưa đo chi phí AI thực, phụ thuộc Auth.js.
