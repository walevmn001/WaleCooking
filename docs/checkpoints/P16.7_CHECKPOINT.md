### DATABASE_DESIGN.md
- Đánh giá **8 entity đề xuất** → kết luận **6 entity mới** (`ImportSource`, `ImportJob`, `ImportJobItem`, `RecipeExtraction`, `RecipeTranslationDraft`, `DuplicateCandidate`) + **11 enum mới**; **tái sử dụng** `RecipeSource`, `RecipeTranslation`, review (`ContentReview`/`ContentReviewRecord`/`ReviewDecision`), `AuditLog` (thay `ImportLog`).
- Mỗi entity nêu: mục đích, fields/types, relations, unique, indexes, cascade, retention, idempotency (kèm DDL phác thảo Prisma — **ĐỀ XUẤT**).

### API_DESIGN.md
- **10 endpoint admin** đúng yêu cầu: tạo job, thêm URL, khởi chạy discovery, xem tiến độ, chi tiết item, retry, cancel, approve/reject, publish, lịch sử + hỗ trợ (sources, worker tick).
- Bám quy ước repo: `app/api/v1/admin/**`, `handle`/`jsonOk`, envelope `{error:{code,message}}`, `getCurrentActor()` + `requirePermission()`.
- **Một cửa publish** duy nhất (`RecipeService.create`→`publish`), không auto-publish; mọi thao tác `AuditLog`.
- Ghi rõ **phụ thuộc Auth.js** (blocker B-P06-02) + **permission importer** cần bổ sung (`import:read/manage/approve/publish`, `source:manage`).
